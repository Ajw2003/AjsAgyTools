# Project Documentation Skill

Manages documentation across the project lifecycle, ensuring technical specs, architectural decisions, and agent handover artifacts remain accurate and up to date.

## Workflow

1. **Locate Documentation:** Inspect `docs/` and `docs/agents/` for existing architectural guidelines and domain definitions.
2. **Synchronize Changes:** Whenever code or schemas change, update corresponding `.md` files immediately.
3. **Artifact Generation:** Verify all handover cards (`step-card.html`) and execution summaries adhere to project documentation standards.
